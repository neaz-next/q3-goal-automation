How the saving is calculated

hours saved per cycle = (Σ manual minutes per case − automated hands-on minutes) ÷ 60
  • Manual minutes: the time a tester spends running one case by hand, from setting up the account to checking the result.
  • Automated hands-on minutes: the time a tester spends starting the automated run and reviewing its results, about 10 minutes per suite. The machine's run time is not counted, because nobody has to watch it.
  • One regression cycle runs every case in the module once.

Assumptions

  • Manual minutes are conservative estimates per case. The funded (FN) cases take longest by hand, because they go through a phase pass, an agreement and an admin confirmation first.
  • Automated hands-on time is about 10 minutes per suite, to start the run and review its results.
  • Savings exclude the one-time cost of writing and maintaining the automation.
